## 予測曲線が実線に重なるチャート

「LSTM で株価を予測してみたら、予測曲線が実際の株価とほぼ一致した」。この手の記事を見たことがある人は多いと思います。Qiita で「LSTM 株価予測」と検索すると、似た構成のコードと、実線に吸い付くような予測チャートが何本も出てきます。

今回、その代表格といえる 1 本を検証しました。172 LGTM、コード全掲載、対象はレーザーテック (6920.T)。ただし少し変わったやり方で、**結果を見る前に「何が出たら主張を棄却するか」を文章にして git commit で固定してから**実行しています。

先に書いておくと、記事を書いた方を責める意図はありません。この型の記事は日本語圏で何年も量産されていて、原因は後述するとおり個人の腕というより問題設定の構造にあります。検証したかったのはその構造のほう。同じ趣旨の指摘は Qiita 内にも既にあります。投資助言でもありません。

## やったこと

[falsify-ledger](https://github.com/trow126/falsify-ledger) という公開リポジトリで、検証の台帳をつけています。手順はこうです。

公開されている定量的な主張を 1 つ選ぶ。結果を見る前に、主張の引用・検証手順・判定条件・自分の予測確率を書いて git commit する。無料の公開データだけで検証する。結果がどうであれ、再現スクリプトとログごと公開する。以上。

commit のタイムスタンプが「後出しじゃない」ことの証拠になります。予測が外れたときも Brier score で採点して記録に残すので、都合のいい結果だけ並べることはできません。ちなみに初回 3 件の判定は KILL / KILL / SURVIVE でした。全部 KILL になるならただの難癖ですが、通る主張はちゃんと通っています（3 件目はコスト込みで検証済みの VIX 戦略で、「これは通るだろう」と予測して実際に通ったケース）。

今回固定した判定条件は 1 つだけ。

> 記事のコードを同一データ・同一分割で再現し、テスト期間の RMSE を「前日終値をそのまま予測値とする」ナイーブ予測と比較する。ナイーブが同等以下（モデル × 1.05 以内）なら KILL、モデルがナイーブを 20% 以上上回れば SURVIVE。

事前の予測は P(kill) = 0.95。ほぼ確実に負けるだろうと踏んでいました。

## 結果: 前日コピーが 42% 勝つ

記事のコードを、モデル・分割・前処理・評価ロジックに手を入れずに再現しました（新しい yfinance の仕様差を吸収する機械的な修正のみ。修正内容は全部ログに残しています）。テスト期間 630 営業日、価格スケールでの RMSE がこちら。

| 予測器 | テスト RMSE（円） |
|---|---|
| 記事の LSTM（再現実行） | 2123.49 |
| 前日終値をコピーするだけ | 1231.02 |

判定は KILL。前日の終値をそのまま「明日の予測」にするだけの手抜き予測が、2 層 LSTM に 42% の大差で勝ちました。記事は seed 未設定・epochs=1 なので実行ごとに結果が揺れますが、seed を 0 / 7 / 42 に変えても全部 KILL です（LSTM 側は 2123〜3373 円の範囲で揺れ、どれもナイーブに負けます）。

「予測曲線が実線とほぼ重なる」ように見えた正体は、モデルが前日の値をほぼそのまま出力しているから。1 日遅れでなぞっているだけなので、チャートを重ねれば当然一致して見えます。しかも今回のケースでは、そのコピーにすら大きく負けていました。

ついでに測ったこと（判定には使っていません）も書いておきます。scaler を全期間で fit しているので、テスト期間の高値が訓練時のスケーリングに漏れています（全期間 fit だと max=57490 円、訓練期間だけなら 35600 円）。ただ今回の KILL はこの leakage を記事のまま残した状態で出ており、直せばモデルはさらに不利になります。また「予測が前日終値より上なら翌日買い」という売買ルールに変換してみると、テスト期間 630 日中 544 日ロングで、取引コストを引く前ですら累積 +14.08%。同期間の buy&hold は +21.98% なので、コスト前から負けています。

## なぜこうなるのか

株価の終値はランダムウォークに近く、明日の値の最良の単純推定は「今日の値」です。終値そのものを目的変数にして MSE を最小化すると、「直近の入力をほぼそのまま出す」関数が loss の谷になる。LSTM はこの解を簡単に表現できて、しかもそこに落ちるのが一番楽なので、学習は素直にそこへ向かいます。

結果、チャートは実線に 1 日遅れで吸い付いて「高精度」に見える。RMSE の絶対値も一見小さい。でも前日コピーという自明な基準と比べた瞬間、上乗せ価値がないと分かる。見た目の一致と予測能力を切り分けられる道具はこの baseline 比較だけで、それを省いた記事は型として同じ結論に行き着きます。量産されるのはそのせいです。

## 自分で確かめるには

検証の成果物は [verification/02/](https://github.com/trow126/falsify-ledger/tree/main/verification/02) に全部置いてあります。再現スクリプト、使用データの snapshot（yfinance は仕様が変わるので固定）、実行ログ、seed 追試。判定条件を固定した事前登録本体は `entries/02` にあり、commit timestamp 付きです。

教訓は 1 行で済みます。「LSTM で株価予測」記事を読んだら、前日終値コピーの RMSE と比べているかをまず確認する。比べていなければ、そのチャートは何も示していない可能性が高い。自分のコードなら 3 行で確かめられます。

```python
naive_pred = y_true[:-1]          # 前日の値をそのまま予測とする
rmse_naive = np.sqrt(np.mean((y_true[1:] - naive_pred) ** 2))
print(rmse_model, rmse_naive)     # これに勝てないなら予測できていない
```
